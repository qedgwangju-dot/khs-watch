# 장중 시황 알림의 투신 수급

코스피·코스닥 현물과 해당 지수선물 수급에 `투신(기관 내)`를 표시한다.
적용 경로는 급락 시작·확대·종료·장마감, 수급 급증, 수급·업종 정밀분해,
기존 파생·대체 감시에서 사용하는 공통 수급 요약이다.

## 원자료와 결측

- 현물 및 기존 금액 단위가 검증된 t1602 계열: `sv_03`.
- 상품이 검증된 t8463 지수선물: `invcode=0003`, `invmsamt`, `invmsvol`.
  코드·금액·정수 수량을 확인할 수 없으면 투신만 보류한다. 기관계 값으로 대체하지 않는다.
- 업종 UBM: 투자자 코드 `0003`. t1621 업종 이력: `invcode=0003`, `invmsamt`.
- 시작이나 종료 원값이 없으면 구간 차이는 확인 불가다. 과거에 투신을 저장하지 않은
  기준점은 0으로 취급하지 않는다. 기관 값을 투신으로 복사하지 않는다.
- t8463와 업종 수급의 환산 단위 미확인 표시는 유지한다. 원자료 금액 크기로 단위를 추정하지 않는다.

## 포함 관계와 감지 기준

투신은 기관계에 포함되는 하위 항목이다. 외국인·기관·개인의 기존 최다매도 비교와
상호 배타적인 투자자 집단의 검산 합계는 그대로 유지한다. 기관과 투신을 더하거나
두 독립 집단이 동조했다는 근거로 확신도를 높이지 않는다. 투신 매수·매도 방향은 별도 표시한다.

투신도 기존 5분 수급 급증 감시에 포함한다. 코스피는 기존 현물 900억원 또는 선물
1300억원 단독 기준, 현물 300억원·선물 450억원 동시 기준을 사용한다.
코스닥은 기존 현물 150억원 기준을 사용한다. 시장·주체별로 10초 이상 새 원자료와
누적 매수 증가를 두 차례 확인하고 기존 20분 재알림 제한을 적용한다.
기관과 투신의 확인 대기·재알림 상태는 서로 덮어쓰지 않고 기존 인계 파일에 각각 보존한다.

## 검증 범위

단위·상품·시각 경계와 기관 포함 관계는 오프라인 회귀에서 검증한다. 기존 LS 조회 전용
진단은 동일한 조회의 투신 원값과 코드 검증 상태도 보존한다. 조회 전용 진단이나 저장 응답
재생을 실제 시장 알림 발송·사용자 기기 수신 확인으로 해석하지 않는다.
