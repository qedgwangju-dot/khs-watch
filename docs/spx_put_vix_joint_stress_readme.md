# SPX 풋옵션·VIX 동반위험 감시: 출처·경보·실패모드

## 목적과 중복 방지
기존 US Positioning Telegram Watch(일반 주식·지수 옵션 P/C 및 수급 리포트), Korea Credit Spread Watch(CP–CD, AA-), Global Rates Watch의 기능과 상태파일은 변경하지 않는다.
이 작업은 **SPX+SPXW 풋/콜 계약비와 VIX 동시 악화만 별도로 감시**한다. 풋 계약수·명목금액·지급 프리미엄·미결제약정은 동일하지 않다. 풋 거래는 신규 매수·청산·매도를 모두 포함하므로 하락에 베팅한 돈으로 단정하지 않는다.

2026-10-23 공개 캡처의 '명목금액 사상 최대'(가장 오른쪽에 2027-12-10이라는 미래 날짜 축 포함)는 거래계약별 합산법, 계약 명목금액 정의, 사전·사후 거래 중복, 원본 조회 링크가 확인되지 않아 공식 검증 완료가 아니다. 알림의 진입 조건에 절대 포함하지 않는다.
첫 번째 세계금융위기 차트는 2008년 역사적 낙폭/회복일이며 현재 위기를 예측하는 실시간 지표가 아니다. MSCI World Quality의 2008년 자료는 지수 출시 이전 구간의 백테스트임에 유의한다.

## 공식 원천
- Cboe 일별 시장통계의 SPX+SPXW 섹션: 날짜별 URL \`https://www.cboe.com/markets/us/options/market-statistics/daily?dt=YYYY-MM-DD\`. 거래일 화면에 표시되는 날짜와 조회 대상의 일치 검증, 콜·풋·전체 거래량 합계, 콜·풋·전체 미결제약정 합계, 공개 풋/콜 비율 대조.
- Cboe VIX 장기 일별 공식 CSV: \`https://cdn.cboe.com/api/global/us_indices/daily_prices/VIX_History.csv\`. 같은 미국 거래일의 종가만 사용한다.
- 거래일 달력은 XNYS. 주말·휴일 제외. 해당 날짜 한쪽 공식 발표가 지연되거나 일치하지 않으면 이전값으로 대체하지 않고 데이터 조회 단계가 실패한다.
- 프리미엄·명목거래금액은 확인된 공식 상세자료가 없으면 **확인 불가**로 유지.

## 자체 경보 기준
- 안정: 아래 동시 조건 미충족.
- 주의: SPX+SPXW 풋/콜 거래계약 비율 ≥1.40 **그리고** VIX 종가 ≥25.
- 악화: 풋/콜 ≥1.70 **그리고** VIX ≥30.
- 심각: 풋/콜 ≥2.00 **그리고** VIX ≥40.
- 회복: 최근 3개 미국 주식시장 공표 영업일 연속 해당 하향 조건을 둘 다 충족. 심각→악화 비율 <1.80·VIX <35, 악화→주의 비율 <1.50·VIX <28, 주의→안정 비율 <1.30·VIX <23.
- 가장 위험한 실측 상태로 상승은 즉시, 하락은 3일 확인 후 통지. 단계는 금융당국의 공식 등급이 아니며 **금융위기 확정 판정이 아니다**.
- 10월 23일 공식 Cboe 콜 2,199,681계약·풋 2,745,718계약·풋/콜 1.2482, VIX 19.45 ⇒ 안정, 정상적으로 위험경보 미발송.

## 일정·알림
한국시간 화~토 10:15, 11:15, 12:15 재조회. GitHub Actions 지연 가능. 동일 미국 거래일·같은 사건에 중복 알림 금지. GitHub 상태파일은 \`data/spx_put_vix_joint_stress_state.json\`.
- GitHub 코드 변경 push는 **공식자료 미발송 검증**. 시장위험이 새로 판정될 때에만 지정 텔레그램 봇 \`@khs8879887988798879_bot\`으로 전송한다.
- [format-sample] 커밋은 "새 시장 경보가 아닙니다" 문구의 단 1회 검증 메시지이며 위험 단계 상태와 중복키는 변경하지 않는다.
- 전송 후 Telegram API의 메시지 전체 본문·수신 대화방 ID를 확인한 경우에만 경보 상태를 기록한다. GitHub Commit 실패 직후 재시도하면 외부 중복 가능성이 완전히 0이 되지는 않는다.
- 상태파일이 없는 최초 정상 실행은 최근 여섯 미국 주식시장 거래일을 backfill하고, 이상 신호가 없다면 기준선만 저장해 조용히 종료한다. 이후 같은 거래일도 원문 재조회하여 **공식 정정 발생 시** 기준 숫자와 필요 경보를 새로 검증한다.
- 공식자료·권한·연결 실패시 추정치 발송 금지. GitHub Actions 실행 실패 기록을 검토해야 한다. 별도 장애 알림은 현재 구성에 없음.
