# 코스피·코스닥 장마감 알림

거래소 세션이 끝나면 기존 감시·봇·수신 경로에서 코스피와 코스닥을 각각 한 번 정리한다.
오전/오후 인계, 휴장, 테스트 실행을 장마감으로 세지 않는다.

## 대상과 수치

- 마감까지 진행 중인 급락 사건이 있으면 그 사건의 시작과 저점 구간을 정리한다.
- 진행 중인 사건이 없으면 장중 종료된 마지막 사건을 정리하고 종료 시각을 표시한다.
- 장중 종료 시 사건과 시작→저점 수급 판정을 함께 복사한다. 이후 수급 버퍼가 없어져도 다른 시점의 수급으로 대체하지 않는다.
- 기록된 사건이 없는 시장도 장마감 요약을 보낸다. 확인 범위는 감시에서 수집된 자료이며, 수급 주도자를 만들지 않는다.
- 신선한 마감 이후 시세가 없으면 해당 시장의 마감 시세를 보류한다. 직전 가격을 종가나 0으로 대체하지 않는다.
- 마감 후 LS 조회 시세와 독립적으로 확인된 거래소 공식 종가를 구분한다.
- 두 시장의 당일 누적 프로그램 수급을 각각 조회한다. 기존 원응답·단위·시각·검산 gate와 보류 사유를 유지한다.
- 현물·선물·프로그램 모집단을 합산하지 않는다. 투신은 `투신(기관 내)`로 별도 표시하며 기관에 더하지 않는다.

## 저장과 전송

`daily_close` 인계 상태에 거래일, 시장별 마지막 종료 사건, 두 마감 본문/사건 식별자/본문 SHA, 확인된 메시지 ID를 보존한다.
두 본문을 첫 발송 전에 고정하며, 확인된 시장은 다시 보내지 않는다.
확인 전 중단된 경우 기존 전송 저널의 동일 요청 승인을 재사용한다. 응답 유실/불확실 상태의 재전송 차단은 그대로 적용한다.
한 시장의 원천 보류는 해당 본문에 표시하고 다른 시장의 정리를 계속한다.
발송 실패가 생기면 다른 시장도 확인을 시도한 뒤 실패를 보존한다. 실패를 정상 완료로 표시하지 않는다.

## 2026-10-20 실제 입력 회귀

실행 `39339679091`, 아티팩트 `12245650360`에서 코스피는 15:16:25에 종료 알림 ID888이 확인됐고,
마감에는 코스닥 ID891만 있었다. 기존 코드는 활성 사건만 마감 대상으로 삼아 코스피를 제외했다.
당시 인계에는 두 시장의 활성 사건이 모두 비어 있었고, 프로그램 마감 조회도 코스닥만 있었다.

`scripts/test_fixtures/market_close_pair_20261020.json`은 이 실행의 저장된 사건·정확 시각의 가격·수급 스냅샷에서 만든 읽기 재생 입력이다.
원래 전송 본문을 새로 보낸 기록이 아니며, 이후 HTTP 가격을 끼워 넣지 않았다.
수정 전 main의 `run()` 재생은 코스닥만 반환하고, 수정 후에는 코스피와 코스닥 두 마감 결과를 반환한다.
