# 엔캐리 청산 감시 사양

## 검증된 핵심 논리

### 1. JGB 10년 3%의 의미

- 일본 10년 JGB 3.0%는 **엔캐리 자동 청산선이 아니다**.
- BOJ의 공식 방어선도 아니다.
- 다만 일본 FY2026 예산의 국채 이자비용 계산 가정금리와 겹치는 **심리적·재정적 중요선**이다.
- 3% 돌파는 일본 국내채권의 절대수익률 매력을 높여 해외채권·해외자산의 상대 매력을 낮출 수 있다.
- 이에 따라 일부 일본 자금의 국내 환류, 엔화 매수 압력, 해외자산 수요 둔화 가능성이 커질 수 있다.

가능 경로:

JGB 10Y 3% 돌파
→ 일본 국내채권 매력 상승
→ 해외자산 투자 매력 상대적 감소
→ 자금 일부 일본으로 환류
→ 엔화 매수 압력
→ 엔캐리 포지션 부담

단, 이 연결은 **가능 경로**이지 자동 반응이 아니다.

### 2. 실제 엔캐리 청산에서 더 중요한 선행 신호

우선순위는 다음과 같이 둔다.

1. BOJ 정책금리·BOJ OIS 인상확률 상승
2. 일본 2년물 상승
3. 미·일 단기금리차 축소
4. USD/JPY 급락 = 엔화 급등
5. FX 변동성 급등
6. 일본 5년·10년물 동반 상승
7. Nikkei·Nasdaq 동반 약세와 VIX 상승

핵심 조건:

- BOJ 정책금리·일본 단기금리 ↑
- JGB 2Y·5Y·10Y ↑
- 미국 금리 ↓ 또는 미·일 금리차 축소
- USD/JPY 급락 = 엔화 급등
- FX 변동성 급등

위 조건이 여러 개 동시에 충족될 때 **엔캐리 청산 위험 강화**로 판정한다.

### 3. 2024년 8월 사례

2024년 8월 급락은 일본 10년물 3% 때문에 발생한 것이 아니다.

당시 핵심 경로는:

BOJ 인상 및 추가 인상 기대
→ 일본 단기금리 상승 기대
→ 미국 고용 둔화·Fed 인하 기대
→ 미국 금리 하락
→ 미·일 금리차 급속 축소
→ 엔화 급등
→ 엔화 숏·캐리 포지션 손실
→ 레버리지 강제청산
→ 글로벌 위험자산 매도
→ Nikkei 급락

당시 10년 JGB는 약 0.75~1.0% 수준이었으며, 3%와 무관했다.

### 4. 현재 2026년과 2024년의 차이

2024년 8월 BOJ 정책금리는 0.25% 수준이었다.
현재는 정책금리가 1.0%이고 추가 인상 기대가 높아질 수 있어 일본 전체 금리곡선이 위로 이동하는 구조다.
따라서 현재는 단순한 한 차례 인상 쇼크보다 **엔화를 싼 조달통화로 쓰는 구조 자체가 점점 불리해지는 과정**으로 본다.

## Telegram 경보 단계

### 단계 0 — 정상
- JGB 10Y 3% 미만
- 일본 2Y·5Y 안정
- USD/JPY 안정 또는 상승
- 미·일 단기금리차 유지

### 단계 1 — 구조적 경계
- JGB 10Y 3.0% 이상
- 또는 일본 2Y·5Y가 동반 상승
- 단, USD/JPY 급락이 없으면 엔캐리 청산으로 단정하지 않는다.

### 단계 2 — 엔캐리 압박
아래 중 3개 이상 동시 충족 시:
- JGB 10Y ≥ 3.0%
- JGB 2Y·5Y 동반 상승
- BOJ 인상확률 상승 또는 정책금리 인상
- 미·일 단기금리차 축소
- USD/JPY 하락 전환
- FX 변동성 상승

### 단계 3 — 실제 청산 위험 강화
아래 핵심 3개를 반드시 포함하고 추가 확인 신호가 동반될 때:
- 일본 단기금리·BOJ 기대 상승
- 미·일 단기금리차 축소
- USD/JPY 급락 또는 일간 급락

추가 확인:
- FX 변동성 급등
- VIX 상승
- Nikkei·Nasdaq 동반 약세
- 레버리지 자산·고베타 자산 급락

## 해석 잠금

- `JGB 10Y 3% = 엔캐리 자동청산`이라고 쓰지 않는다.
- `2024년 8월 급락 = JGB 3% 때문`이라고 쓰지 않는다.
- Nikkei·Nasdaq 하락은 선행 신호보다 실제 청산의 **후행 확인 신호**로 취급한다.
- JGB 3%만 충족하고 USD/JPY가 약세(엔화 약세)라면 `구조적 경계`로만 알린다.
- BOJ OIS·2년물·USD/JPY가 동시에 움직이면 10년물 3%보다 우선해 위험도를 높인다.

## 자동화 데이터 원칙

- 공식·일일 데이터: 일본 재무성 JGB, 미국 재무부 국채, Federal Reserve/FRED 환율.
- 장중 즉시 경보에는 별도의 실시간 시장 데이터가 필요하다.
- BOJ OIS 인상확률은 공식 공개시계열이 아니므로, 신뢰 가능한 시장 데이터 제공처가 확보되기 전에는 자동 수치로 임의 추정하지 않는다.
- 자동 수치가 없으면 `BOJ OIS 확인 불가`로 표시하고 일본 2년물·USD/JPY·미일 금리차를 대체 선행 신호로 사용한다.
