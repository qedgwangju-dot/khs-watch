# 글로벌 금리·엔캐리 경보 최신성 원칙

- 보고 시각과 데이터 기준일을 분리한다.
- 공식 일일 자료는 실행 시점에 공개된 가장 최신 값을 다시 조회한다.
- 미·일 2년 금리차는 일본 2년 JGB와 미국 2년 국채의 기준일이 정확히 같을 때만 계산한다.
- 기준일이 다르면 숫자를 억지로 계산하지 않고 `기준일 불일치 — 계산 보류`로 표시한다.
- FRED USD/JPY 일일값이 최신 금리 기준일보다 오래되면 현재 엔화 신호로 사용하지 않고 `공식 최신 일일 참고값`으로만 표시한다.
- 오래된 값으로 새 진입·해제 이벤트를 만들지 않으며 해당 상태도 소비하지 않는다.
- 최신값 조회 실패 시 과거 값을 현재값처럼 재사용하지 않는다.
