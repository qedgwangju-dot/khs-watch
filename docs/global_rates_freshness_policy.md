# 글로벌 금리·엔캐리 경보 최신성 원칙

- 보고 시각과 데이터 기준일·기준시각을 분리한다.
- 공식 일일 자료는 실행 시작 때 한 번만 읽지 않고 Telegram 보고서를 만들기 직전에 다시 조회한다.
- 일본 재무성 JGB와 미국 재무부 금리는 `실시간`이라고 쓰지 않고 각각의 `공식 최신 일일치`와 기준일을 표시한다.
- 미·일 2년 금리차는 일본 2년 JGB와 미국 2년 국채의 기준일이 정확히 같을 때만 계산한다.
- 기준일이 다르면 숫자를 억지로 계산하지 않고 `기준일 불일치 — 계산 보류`로 표시한다.
- USD/JPY 현재 신호는 기존 Yahoo query1/query2 5분 데이터를 교차확인한 값만 사용하고 관측시각을 표시한다.
- USD/JPY 교차확인값이 12분보다 오래됐거나 두 경로가 불일치하면 현재 신호를 계산하지 않는다.
- FRED H.10 USD/JPY는 공식 일일 참고값으로만 보존하며 현재 환율처럼 표시하지 않는다.
- 오래되거나 기준일이 맞지 않는 값으로 새 진입·해제 이벤트를 만들지 않으며 해당 상태도 소비하지 않는다.
- 최신값 조회 실패 시 과거 값을 현재값처럼 재사용하지 않는다. `현재값 확인 실패`라고 명시하고 해당 신호 판정을 보류한다.
