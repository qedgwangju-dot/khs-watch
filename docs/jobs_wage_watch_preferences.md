Jobs Wage Watch 해석 고정 기준

- 연준 반응함수 구역은 반드시 포함한다.
- 고용·임금 조합이 금리 방향에 주는 신호를 첫 줄에서 직관적으로 표시한다.
- 예시 표현:
  - 고용 약함 + 임금 둔화 → 인하 쪽
  - 고용 약함 + 임금 강함 → 인하 쪽 신호는 있으나 제한적
  - 고용 강함 + 임금 강함 → 동결·인상 쪽
  - 방향 엇갈림 → 중립
- 단, '고용축 인하 쪽'과 'Fed 실제 금리인하 확정'은 분리한다.
- 최종 Fed 판단은 최신 FOMC 공식 성명, CPI·PCE·임금·기대인플레이션을 결합해 판정한다.
- 보고서는 정보량을 줄이지 않고 가독성 있게 구성한다. # 마크다운 표시는 사용자 알림에서 제거한다.
- 자동 알림은 새 공식 발표에만 전송하고 중복 판정 키를 유지한다.
