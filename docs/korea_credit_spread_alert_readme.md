# 국내 신용스프레드 경보 운영·재발 방지 기준

## 가독성·방향
첫 3줄에 현재 경보 단계, 최근 5영업일 방향(단기 CP–CD/AA- 회사채를 각각 구분), 직전 영업일 변화를 반드시 표시한다. 다른 방향으로 움직일 때는 혼합하여 '전체 악화'라고 쓰지 않는다. 5영업일 변화가 ±2bp 미만이면 보합으로 표기하며 이는 자체 표시 기준이다. 원문 금리 4종, 두 스프레드, 전일·5영업일 변화, 다음 위험선, 회복선, 원천 날짜를 빠뜨리지 않는다.

## 원천 및 공식 식별 코드
한국은행 경제통계시스템(ECOS) 통계표 817Y002:
- CP 91일: 010503000
- CD 91일: 010502000
- 회사채 AA- 3년: 010300000 (다른 민간평가 수익률 010310000과 구별)
- 국고채 3년: 010200000

CP–CD(bp) = (CP 금리 연% − CD 금리 연%) × 100.
AA- 신용스프레드(bp) = (회사채 AA- 3년 금리 연% − 국고채 3년 금리 연%) × 100.
5영업일 변화(bp) = 해당일 금리 차이 − 5공표영업일 전 금리 차이.

원천 네 계열의 최신 공표일, 금리 단위, 이름·코드, 날짜, 수치 유효성 중 하나라도 불일치하면 이전 공통 날짜로 회귀하여 현재처럼 표시하지 않는다. 추정·재사용·임의 값 보내기를 금지한다.

## 경보 등급(두 지표 중 하나라도 충족하면 해당 상위 단계)
관찰: CP–CD 30bp 이상 또는 AA- 70bp 이상.
주의: CP–CD 50bp 이상 또는 AA- 80bp 이상.
악화: CP–CD 70bp 이상 또는 AA- 90bp 이상.
심각: CP–CD 100bp 이상 또는 AA- 120bp 이상.

안정 복귀: CP–CD 30bp 미만 + AA- 70bp 미만 동시 5영업일 연속. 그 밖의 경보 하향은 코드의 DOWN 표에 따라 두 조건을 동시 3영업일 확인. 현재 실측 단계와 회복 확인 전 유지되는 알림 단계가 다르면 둘 다 표시한다. 이 단계는 금융당국의 공식 위기 등급이 아니다.

## 발송 무결성 및 배포
텔레그램 봇은 @khs8879887988798879_bot, 기존 GLOBAL_RATES 인증정보를 사용한다. 한 메시지 최대 1,600자로 자르지 않고, Telegram API 응답 원문 text와 보낸 HTML 태그 제거 후 문자열을 일치 비교한다. 성공 수신 확인 후에만 경보 상태를 저장하고 동일 사건을 재발송하지 않는다. 코드 변경으로 발생하는 자동 실행은 미발송 확인을 기본으로 한다. 단 한 번의 형식 검증 커밋 표시인 [format-sample]은 '새 경보가 아님'을 포함해야 하며, 실제 경보 상태를 변경하지 않는다. 샘플 재발송은 원칙적으로 금지한다.
