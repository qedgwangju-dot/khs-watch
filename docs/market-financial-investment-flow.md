# 급락 알림의 기관·투신·금융투자

코스피·코스닥 급락 시작·확대·종료·장마감 알림의 현물과 해당 지수선물에
기관, 투신(기관 내), 금융투자(기관 내)를 표시한다. 기존 외국인·개인도 유지한다.
투신·금융투자는 기관계에 포함되므로 기관과 더하거나 독립 집단의 동조로 세지 않는다.
최다매도와 검산은 기존 외국인·기관·개인 등 상호 배타적 집단을 사용한다.
