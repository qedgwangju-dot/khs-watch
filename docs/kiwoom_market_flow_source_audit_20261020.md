## 수집과 표시

코스피·코스닥의 현물, 지수선물, 프로그램을 서로 다른 수급으로 보존한다. 투자자별 현물 누적값과 특정 사건·5분 구간의 변화도 구분한다. 투신은 기관의 부분집합이며 별도로 더하지 않는다.

## 원자료와 보호 장치

- 공식 API 카탈로그 고정본: [Kiwoom-Securities/Kiwoom-REST-API](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/953e5dbff123f437ab4d11a78a95191a685eb51f/kiwoom/_data/kiwoom_api_spec.json).
- 이 카탈로그 SHA256: `42a7b3912c9d9588c83bdc2db7779c8d2e038703a2b5562e54ef46ae905cba79`.
- 시장 데이터 요청은 ka10051·ka90005만 허용한다. 계좌·주문 인터페이스가 없다.
- 원응답 bytes/base64/SHA256·요청 범위·조회시각·실제 체크아웃 SHA·실행 ID를 `out/market_source_evidence`에 남긴다. 인증값·토큰·인증 헤더는 보존하지 않는다.
- 현물 보완 문구를 만들기 전에 보존 원응답을 다시 파싱해 금액·범위·조회시각을 대조한다. 누락·변조·오래된 증거는 보류한다.
- 프로그램 순매수의 실제 `--` 음수 표기는 해당 순매수 필드에서만 처리하고 매수−매도와 독립 원화 원표로 부호를 대조한다.
- 캐시는 기존 관측시각을 유지한다. 조회 재사용으로 관측을 새 시각으로 바꾸지 않는다. LS와 키움 또는 원값과 억원을 구간 차분에서 섞지 않는다.
- 기존 수집의 실패는 보존하며, 신선하고 검증된 프로그램 대체가 성공한 경우에만 해당 LS 프로그램 오류를 별도 회복 기록으로 이동한다.

## 실제 조회와 운영 확인의 구분

2026-10-20 20:38 KST의 허용된 로컬 읽기 조회 8건이 인증·HTTP200·return_code0을 통과했다. 보존된 두 시장 현물 원응답을 회귀 fixture로 사용한다. 이 fixture는 실제 알림·운영 실행 증거가 아니다.

21:05~21:06 KST 새 클라이언트 읽기 조회에서 현물 두 시장의 누적값 검산과 원자료 기반 문구 재검사가 통과했다. 프로그램은 같은 시각 KRX·NXT 원표를 확보하지 못해 보류했다. 이를 전 수급 확보 또는 장중 운영 검증 완료로 표시하지 않는다.

별도 CI 원자료 작업은 전송기·이벤트·운영 state를 사용하지 않는다. 현물 두 시장의 조회·파싱은 필수이며, 프로그램의 검증 불가와 지수선물 미확보는 `coverage=PARTIAL`, `full_market_flow_coverage_verified=false`로 기록한다. 실제 일반 알림의 발송과 수신은 다음 자연 운영의 영수증·본문·상태로 따로 확인해야 한다.

기존 알림 기준, 일정, 대상, 발송 영수증, 운영 state 및 다른 감시의 파일은 변경하지 않는다.
