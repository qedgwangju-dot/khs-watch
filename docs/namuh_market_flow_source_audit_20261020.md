# 나무 수급 보완 연결 및 검증 범위

## 실제 접속

- 사용자의 나무 API 대체 요청에 따라 기존 암호화 인증정보를 사용했다.
- 현재 PC와 GitHub `ubuntu-latest`에서 정상 공식 인증·시세 조회가 확인됐다.
- 최초 GitHub 읽기 검증: [39428460268](https://github.com/qedgwangju-dot/khs-watch/actions/runs/39428460268).
  - 실제 checkout `1a4bbe3bb20e287ce230086a76ddb5f9752bb2dc`.
  - KOSPI·KOSDAQ 각각 현물, 선물 수량, 프로그램 조회 6건 성공.
  - artifact `12266908289`, ZIP SHA256 `2014b07a1f441ac72003e399f0afa51db5853b6ad303bc2fe3717fd03896915c`.
  - 알림 발송과 운영 상태 쓰기는 없다. 이 검증을 실제 알림 수신으로 세지 않는다.
- 유료 서버·AWS·외부 스케줄러는 도입하지 않았다. 기존 키움 GitHub 요청의 8050 기록은 보존하며 나무 성공으로 과거 키움 거절 원인을 확정하지 않는다.

## 공식 계약과 허용 경로

- [NH 공식 공통 안내](https://www.nhplug.com/llms.txt).
- [국내파생 OpenAPI 명세](https://www.nhplug.com/openapi-docs/krfuture/openapi.json), 저장 SHA256 `502e4813cae12ce46283a4c989435398bff90d2d8618c1dd49f8b3a1aaf970a7`.
- `/krfuture/quote/v1/tradingStatus`: 시장 `1` 코스피 현물, `2` 코스닥 현물, `3` 선물, `6` 코스닥150선물.
- `/krfuture/quote/v1/timeProgramTrading`: 시장 `1` 코스피, `0` 코스닥. 투자자 조회와 시장·금액 선택자의 의미가 다르므로 별도 생성한다.
- 두 시세 인터페이스만 허용한다. 계좌·주문·정정·취소는 호출하지 않는다.
- 일반 일별 `cycle_cls_code=2`를 사용한다. 여러 날짜가 누적되는 `3`을 당일 값으로 읽지 않는다.
- 토큰은 24시간 만료 기준으로 재사용한다. 파일은 앱키·시크릿에서 도출한 키로 암호화하며, GitHub cache에는 암호문만 넣는다. 인증 요청 URL·응답·토큰은 증거 파일과 로그에 저장하지 않는다.

## 수치와 해석

### 현물

- `UNT`의 최신 일별 행은 KRX+NXT 범위이다. 날짜와 `timez12`를 함께 검사하고 오래된 첫 행을 다른 행으로 대체하지 않는다.
- 금액 배율은 크기로 추정하지 않는다. 별도의 같은 시장 KRX 시각 원표와 공개 원화 표를 정확히 같은 시각에 대조하고, 10개 투자자 항목에서 유일하게 일치하는 `1,000,000원/원값`을 요구한다.
- 공개 표의 단위 계약은 [Npay 투자자 동향](https://stock.naver.com/market/stock/kr/trend/trader)의 공개 JS가 현물 `diffValue / 1e8`을 `억`으로 표시하는 것을 근거로 한다. 저장 bundle SHA256은 코드에 고정했다.
- 외국인계는 대조 표의 외국인 `9000`과 기타외국인 `9001`을 합쳐 대조한다. 이를 키움의 외국인 단독 값과 같은 값이라고 부르지 않는다.
- 개인/기관/외국인계/기타 집단 및 기관 내 세부 합계를 검산한다. 투신은 기관 내 관측이며 더하지 않는다.
- 이 검증은 같은 시각 KRX 원표에서 단위와 분류를 확인한 것이다. 최신 통합 현물 금액 전체의 독립 확인으로 승격하지 않는다.

### 프로그램

- 금액 조회의 원필드 이름에 `qty`가 있어도 수량으로 해석하지 않는다.
- 당일 일별 누적행의 차익·비차익·전체 매수/매도/순매수 9개를 각각 검산한다.
- 같은 날짜의 공개 KRX 및 NXT 최신 원화 원표와 9개가 모두 백만원 표시 차이 이내에 일치해야 표시한다.
- 두 거래소의 최신 공표 시각은 다를 수 있다. 이를 하나의 같은 시각으로 합치거나 사건 구간/5분 수급의 기준점으로 쓰지 않는다.
- 프로그램 투자자별 행렬은 이 API에 없다. 외국인·기관·투신으로 프로그램 금액을 배분하지 않는다.

### 선물

- 선물 선택자 `3`, 코스닥150선물 `6`의 당일 투자자 순매수 **수량**을 읽고 계약 수량으로 표시한다.
- 수량 집단 합계와 기관 세부 합계에는 반올림 허용을 주지 않는다.
- 금액으로 변환하지 않는다. 원화 금액 검증과 세부 상품 범위 확인을 완결했다고 주장하지 않는다. 시장 `3` 표시는 나무 명세의 선물 구분이며, 기존 LS의 KOSPI200 상품 검증을 대신하지 않는다.

## 알림 적용과 보존

- 나무가 설정되어 있으면 기존 알림의 당일 누적 보완 경로가 나무를 사용한다. 나무 미설정 때 기존 키움 보완 경로를 유지한다.
- KOSPI/KOSDAQ 급락·회복·마감·기존 수급 알림 및 빠른 가격 보완 알림에 같은 제한을 표시한다.
- 나무 원값을 기존 LS 사건 구간이나 5분 차이에 혼합하지 않는다. 기존 매매 주체 판정·감지 임계값·전송 경로·예약·seen/state는 변경하지 않는다.
- 본문 직전에 보존 증거의 해시, 원바이트, 시장, 날짜, 원값과 단위를 다시 재생한다. 실패한 요소는 보류하고 다른 요소와 가격 감시는 계속한다.
- 소수 원값은 증거에 보존하고 짧은 보완 표시에서만 억원 정수로 반올림한다. 0과 결측을 구분한다.
- 일반 발송을 인위적으로 만들거나 수동 dispatch/재전송하지 않는다. 운영 적용 뒤 자연 실행의 실제 코드·본문·영수증·저장은 별도 증거로 확인한다.
